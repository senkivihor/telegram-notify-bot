# Agent Context: Atelier Telegram Bot (Senkiv)

## 1) Project Overview

- **Project Name:** Atelier Telegram Bot (Senkiv)
- **Purpose:** Telegram bot for an atelier owner that helps calculate service prices using LLM support (Gemini 2.5 Flash) and manage client communication.

## 2) Tech Stack & Architecture

- **Language:** Python 3.10+
- **Main Libraries:** `pyTelegramBotAPI`, `google-generativeai` (Gemini API)
- **Repository Structure:**
  - `main.py` — Entry point, Telegram handlers, core bot logic.
  - `services/ai_service.py` — LLM interaction logic, prompt construction, strict output parsing.
  - `price_data.py` — Constants storage, especially `PRICE_LIST_TEXT` as the source of truth for base prices.
  - `tests/` — Unit tests (`unittest` or `pytest`).

## 3) Communication Guidelines (CRITICAL)

- **Primary Language:** STRICTLY Ukrainian (`UA`) for all client-facing and admin-facing messages generated by the bot or recommended by any AI Agent.
- **Tone:** Professional, friendly, helpful, and marketing-friendly.
- **Style Intent:** Keep business constraints clear, but phrase them as polite, premium-service reminders.

## 4) Core Business Logic: Pricing Calculator

Future changes must preserve or improve this logic without regressions.

- **LLM Responsibility:**
  - LLM analyzes client request (text/images).
  - LLM outputs only:
    - `task_summary`
    - `estimated_minutes`

- **Smart Range Override (mandatory):**
  1. Compute base calculated price:
     - `calculated_price = estimated_minutes * hourly_rate + costs`
  2. Parse and obtain `min_list_price` from `PRICE_LIST_TEXT` for matched task.
  3. Enforce floor:
     - `final_client_price = MAX(calculated_price, min_list_price)`
  4. Under no circumstances may final client price be lower than price-list minimum.

- **Range Generation Rule:**
  - Default: display final price to client as a range (example: `500-600 грн`).
  - Exception: if relevant item in `PRICE_LIST_TEXT` contains a `price_override` note, display a single fixed price instead of a range.

## 5) Implementation Rules

- **Defensive LLM Parsing (critical in `services/ai_service.py`):**
  - Never trust raw LLM formatting.
  - Parse all pricing values strictly to integers.
  - Strip currency marks, separators, spaces, and all non-numeric artifacts.
  - If parsing fails, apply robust defaults and fail safely.

- **Admin Transparency UX:**
  - In admin summary, always show:
    - `📌 База/Мінімум за прайсом`
  - Show this line whenever a price-list match exists (`min_list_price > 0`), even if calculated price is higher and wins in final pricing.

## 6) Required User Interface Element

All client-facing cost estimate messages **must** end with this exact polite reminder:

> "🫧 *Маленьке прохання:* для найкращого результату та турботи про тканину, приймаємо в роботу лише чисті речі. Дякуємо! ❤️"

This block must remain in Ukrainian and appear at the very end of the client estimate message.
